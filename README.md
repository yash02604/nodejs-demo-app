\# Node.js Demo App - CI/CD Pipeline



\## Project Overview



This project demonstrates an automated CI/CD pipeline for a Node.js application using GitHub Actions and Docker.



The pipeline automatically runs when code is pushed to the `main` branch.



\## Technologies Used



\- Node.js

\- Express.js

\- Docker

\- Docker Hub

\- GitHub

\- GitHub Actions



\## Application



The application provides two endpoints:



\- `/` - Displays the application welcome message.

\- `/health` - Returns the application health status.
